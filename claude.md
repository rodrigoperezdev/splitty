# Claude

Claude is an AI assistant developed by Anthropic. It is designed for safe, reliable, and helpful natural language interactions.

## Overview

- **Name:** Claude
- **Type:** Large language model / AI assistant
- **Purpose:** Answer questions, generate text, and help with tasks in a human-like manner.
- **Use cases:** documentation, brainstorming, coding help, summarization, and conversation.

## How to use

- Ask clear questions.
- Provide context when possible.
- Use short instructions for specific tasks.
- For longer tasks, break them into smaller steps.

## Example prompt

```text
Create a short project plan for building a cost-splitting app called Splitty using Next.js and a monorepo layout.
```

## Notes

- Claude is generally used through a web interface or API.
- It prioritizes safe and aligned responses.
- If you need the assistant to follow a specific style, include that instruction in the prompt.
- Use Conventional Commits for all commit messages in this project.
