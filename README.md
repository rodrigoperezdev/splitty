# Splitty

Splitty is a monorepo for a friend cost-splitting app. The repository is split into frontend and backend workspaces.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the frontend:
   ```bash
   npm run dev:frontend
   ```

3. Run the backend:
   ```bash
   npm run dev:backend
   ```

4. Open the frontend at http://localhost:3000 and the backend at http://localhost:4000.

## Workspace structure

- `apps/frontend/` — Next.js + React + TypeScript + Tailwind frontend
- `apps/backend/` — Express + TypeScript backend stub
